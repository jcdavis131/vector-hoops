## Functional Bugs / Races

### 1. Typeahead freeze (main complaint)

`past-modern-game.js`:
- `filteredModern()` loops over `modernPool` (491 players) and calls `.toLowerCase()` each keystroke originally. Latest code builds `_searchIndex` once, but `attachSuggest()` still:
  - Builds 8 `<li>` once (good)
  - Debounces 120ms, but `filteredModern` depends on `VHPastModern.state().modernPool` being populated
  - If user types during `init()` before fetchJSON of `vectors_search_lite.json` (1.2MB) resolves, `buildSearchIndex()` returns null => empty suggestions. No retry.

Fix: guard input disabled until rankingReady, show "Loading players…" placeholder.

### 2. "Loading…" stuck

- `init()` does `Promise.all([searchLite, honors])` with `cache:'force-cache'` first, then fallback no-store. If either 404, whole page throws and hits bottom `main().catch` which writes into `#pack-invalid` — user sees no target.
- No timeout. Vercel edge cache for .json is `public, max-age=31536000, immutable` — stale file after pipeline regeneration keeps browser stuck.

### 3. Map idle pause never resumes on touch scroll

- `shared-map.js` auto-pause after 8s idle sets `embedPaused=true`. Resume only on mousedown/touchstart on canvas, or pause button, or visibility change. Scrolling page doesn't resume, so map looks dead.
- `focusin` on `#guess-input` *pauses* map — opposite of intent (you want map visible while typing).

### 4. Pack state leak

- `PACK_CURRENT_KEY = vh.pack.current` + `vh.pack.<code>` per pack. No LRU cleanup. Heavy localStorage after exploring packs (>50 entries) triggers quota errors on Safari, breaks `saveGuesses()`.

### 5. Mobile tap targets

- `#guess-suggest li` min-height 44px ok, but `.mode-tab` 40px, `.pill` 10px font with 16px tap zone — fails 44px rule from `responsive.css` comment. Lighthouse will flag.

## Performance

- First paint: 980px max-width container, but map alone loads `vectors_map_lite.json` (likely 600KB) + `vectors_search_lite.json` (~2MB?) + `scoring_lite.f32` (300KB) + `honors.json`. No prio hints.
- Canvas DPR=1 saves memory (good), but projection of all 12,966 points each frame still O(N). Mobile throttled to 24fps, but `projectFrame()` still runs on every animation tick.
- `requestAnimationFrame` loop keeps running even when tab hidden until `visibilitychange` fires — waste.

## Recommendations (priority order)

### P0 — Fix "not working"

1. Gate `#guess-input` disabled until `vh:ranking-ready`. Show spinner in placeholder.
2. Add 6s fetch timeout with user-visible retry in `#game-header` — don't throw to console only.
3. In `shared-map.js`, on `focusin` of input, *resume* not pause, and on touch scroll resume too.
4. Normalize `packStorageKey` cleanup: on `abandonPack` remove current, on init sweep >20 keys.

Collapse 7 cards -> 3 stages:

- **Header mini** (1 line): "Daily Court • P#423 • streak 3" + single [?] button

- **Action**: Guess input + guesses list
- Move Mode tabs to sticky top secondary nav (remove from card). Remove `position:fixed` bottom rule in responsive.css.
- Remove three empty pack cards from initial HTML — inject via JS only when `isPack`.
- Remove `ready-banner` negative margin hack — make it real card.

CSS: delete shell.css + final-qa.css loading from play.html; merge into unified.css single source. Keep motion.css (small). Result -2 requests.

### P2 — Polish
