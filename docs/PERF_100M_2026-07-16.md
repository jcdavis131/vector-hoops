### After Optimizations (2026-07-16 night)

#### 1. vercel.json CDN Headers (100M DAU)
```json
"/assets/(.*)\\.(json|js|css|png|webp|svg|woff2|f32|bin)" → public, max-age=31536000, immutable, stale-while-revalidate=86400
"/assets/(.*)\\.f32" → immutable + application/octet-stream
"/sw.js" → public, max-age=0, must-revalidate
"/manifest.json" → 3600 + SWR 86400
"/*.html" → max-age=0 must-revalidate SWR 600 + nosniff
```
- Vercel Edge now serves assets with year-long immutable, free tier R2 cache.
- HTML network-first with SWR ensures fresh Daily puzzle.

#### 2. Payload Shrink — Homepage Critical Path
- Created `vectors_search_lite.json` 1.08MB (was 3.0MB) → 64% reduction, fields only `i,n,s,x,y,z,c` stripped `v`
- Created `archetype_lite.json` 2.44MB (was 3.2MB) → saves 0.8MB
- Homepage now:
  - **Critical: synthetic canvas 0KB + `season_norms 11K` + `vectors_search_lite 1.08MB` deferred to 800ms idle**
