Methods

Every number can be recomputed from source

The games use 14 era-normalised per-100 features for speed and transparency. The research model, MTNN, widens that to 120 features in 17 towers and compresses each season to a 64-d unit vector for neighbour search. The architecture is covered in depth in the Lab.

02

MTNN — the model behind every guess

17 towers → residual towers → a 64-d fingerprint, L2-normalised so cosine is similarity → decoded to archetype (8), position (5) and skills. An 18th family, injury, feeds a durability read-out head rather than an input tower: as an input it measured −0.088 test recall, because durability is not a style axis.

Input 120 feats, mask m∈{0,1}
h = cat([x·m, m]) → 2·d_in per family
Tower 17×: 2d_in→160 LN GELU → 160→32 LN + skip ×2 → 32-d (544 total)
+ season_emb 12-d → 556 → 556→256 GELU → 64 L2
Heads: 8 arch / 5 pos / 14 next / 18 skills (64→16→1)

04

Archetypes — eight types

k-means with K = 8 on the era-z vectors, seeded so it reproduces.

  1. Three-point accuracy (low TOV)
  2. Scoring + shot volume
  3. Defensive glass + rim pressure
  4. Three-point volume + accuracy
  5. Offensive glass (low on-court)
  6. Rim protection + offensive glass
  7. Offensive glass + defensive glass
  8. Playmaking + steals
05

League drift — Procrustes

Orthogonal Procrustes on consecutive-season shared players (≥ 30). Rotation = mean principal angle of Q against the identity; residual = Frobenius norm after alignment; chained to the 1996 root frame; RᵀR = I.

This powers the Trends charts. The biggest summers: 2021–22 at 11.1° and 2022–23 at 7.6°.

06

Skills lens — 0 to 99

Twelve skills, each a fixed linear composite of era-z per-100 stats, expressed as a percentile within the season, so a 90 in 1997 equals a 90 in 2026. Badges start at 90; gold at 97.

recall@10
Can the model find the same player the following season?
purity@20
Do a season’s neighbours share its archetype?
07 · Experimental

Forecast — where a player is headed

Three-season context → next-season embedding (first 8 of 64 dimensions). Same source as the map: embedding_v3_with_text.npz, 12,966 × 64. A torch-lite two-layer temporal transformer with cross-variate attention, 7,096 windows, 5 epochs full-batch, no chronological split, no quantile calibration yet. Not TimesFM-3 (non-commercial) or a validated TimesFM-2.5.

One contract everywhere: /data/timesfm_forecasts.json, 300 forecasts, with an honest failure message if the file is missing.

Future work: chronological, player-aware splits with no leakage; saved seeds and weights; naive-last and drift baselines; MAE / RMSE plus angular error; quantile coverage.

Accuracy harness — blocks a deploy on failure

V2Cluster labels recomputed by nearest centroid; all 12,966 match
V3deadline.json deltas recomputed from raw logs, 0.01 tolerance
V4Chimera determinism across 30 dates; cosine < 0.3 between donors

MTNN extras: leak-free recall@10 via leakfree.py, purity@20, next-profile MAE. ONNX 549 KB.

09

Attribution and limits

  • No lineup or on/off data — the model doesn’t know who shared the floor.
  • A midseason move is a TEAM_ID change, not verified trade metadata.
  • Tracking exists only from 2013; earlier seasons are masked, not imputed.
  • Position coverage is 99.7%.
  • Archetype names describe centroid stats, not scouting reports.
  • A Chimera’s fused vector never existed as a real season.
