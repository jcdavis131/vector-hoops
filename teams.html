How 3 grades are built (no black box)

Sources: draft_history.json 1947-2025 (person_id + overall + team_abbr), vectors.json 12,966 seasons (gp/mpg/total_min + x/y/z + c), salaries_merged.json 16,678 rows (norm_name|season → salary + team), team_base_*.json W/L, CAP_BY_SEASON $24M→$154M.

  • Draft Smarts (actual vs expected by pick): Build expected career total_min curve for picks 1-60 using 1996-2022 drafts averaging career minutes trimmed mean. For 2020-24 picks per team, projected career = actual_min / completion where completion = min(1, seasons/5.5), surplus = projected − expected. Scaling rewards steals (Jokić 41), penalizes busts (0 min → −0.6*expected). Rolling 5yr avg surplus → score = 50 + surplus/35 capped 0-100. Median trimmed.
  • Cap Efficiency (Wins Above Payroll Expectation): Payroll sum from salaries_merged for 2024-25. W per $M = W / (payroll/1M). Rank pct vs 30 teams, median baseline 50, score = 50 + (wpm−median)/median*50. Payroll $ → cap pct = payroll / cap $140.588M. Wins/Payroll tells if dollars turned into Ws.
  • Foresight Deals (early cheap lock): For 2024-25 players 20+ GP, median salary $ + median tm minutes computed. Expected salary = median_sal × (0.4 + 0.8 × tm/median_tm) capped 3×. Surplus $ = expected − actual (positive = bargain). Retained flag if same team 2023-24 and salary growth ≤ cap growth +5%. Bonus 1.25× if retained. Score = 50 + surplus_total/6M×10 capped. Think Jokić-type rookie extension that explodes as embedding jumps + cap rise $123M→$154M (+28%).
  • Composite FOR: 0.35·draft + 0.35·cap + 0.30·foresight. Ranked 1-30 then curved A+ top 7% to D bottom 3% so you actually see letters. Recomputable via pipeline/build_front_office.py — zero deps stdlib.
