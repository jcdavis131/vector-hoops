Shared honesty facts (read before judging)

  • The v5 next-profile head is NOT runnable. mtnn_heads.f32 is 12,966×45 frozen per-row head outputs, not weights; no checkpoint is saved; the saved ONNX is a different stale 119→48 model. Both prototypes therefore steer / attribute labelled baselines, never presented as model predictions.
  • Baselines do not beat carry-forward. Future Explorer's age-curve baseline ties carry-forward (0.4705 vs 0.4732 MAE; v5 saved head 0.4708); Forecast Attribution's K=25 neighbor baseline trails it (0.4805 vs 0.4732). Both demos prove interaction mechanics, not forecast skill — a future runnable, gated model head would slot into the same interactions.
  • Steering / attribution moves are computed, not asserted. Explorer steers are OLS slopes over 10,107 adjacent-season pairs, labelled as correlations, not causal effects. Attribution deltas come from LOSO re-runs of the neighbor search with the signal dropped or scaled.
  • What each demo omits, honestly: Explorer omits new-team steering (team is not in the 14-d vector) and speaks in within-season z units (no raw per-100 values in the saved asset). Attribution states explicitly that true model-internal (tower/gradient/SAE/JEPA) attribution is unavailable — the banned 48-d sources were never used.
  • Success-test evidence (measured, quoted in each lane's NOTES): Explorer — Curry 2016-17 "More threes" +1.0z: FG3A 2.55 → 3.55, FG_PCT 0.18 → −0.09. Attribution — Curry remove scoring: predicted PTS 1.843 → 1.413 (−0.429); Jokić remove playmaking: AST −1.423.
