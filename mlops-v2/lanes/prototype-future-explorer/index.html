Read this first: what is a model prediction here, and what is not

Nothing on this page is a live model prediction. The v5 champion's next-season head cannot be re-run from what is saved: the saved file holds frozen per-row head outputs, not weights, and no v5 checkpoint is saved in the repo. So the forecast you steer is a labelled baseline, computed from real history in the open (see “How every number was computed” below) — never presented as a model prediction. The v5 saved head is shown only as a frozen reference line, and it does not move when you steer, because there is no model to steer through. Steering moves are correlations from real year-to-year changes, not causal proof: players who shot more threes tended to change this way. New-team steering is omitted on purpose — team is not in the 14-stat line and no team-change effect was estimated, so showing one would be invented.

How every number was computed

  • Current line: the player's real 14-stat line for the chosen season, from assets/vectors.json (12,966 player-seasons, per-100 stats z-scored within season).
  • Baseline forecast (age-curve): current line + the average year-to-year change of players in the same age bin, computed from all 10,107 adjacent-season pairs (same person_id, season N → N+1) in vectors.json.
  • Carry-forward: next season = this season, unchanged. The simplest baseline there is.
  • v5 saved head: columns 31:45 of mtnn_heads.f32 (layout [arch 8 | skills 18 | position 5 | next-profile 14] per pipeline/export_mtnn_viz.py), the frozen next-profile outputs v5's export saved per row. No weights are saved, so it cannot be re-run or steered.
  • Steering: steered = baseline + Σ (slider ÷ 100 × slope vector). Each slope vector is the least-squares slope of each stat's year-to-year change on the driver's year-to-year change, over all 10,107 adjacent pairs. Derivation is printed under each slider. This is a correlation, not a causal effect and not a model run.
  • What was omitted, and why: new-team steering (no team variable, no estimated effect); SAE steering, JEPA predictions and trained-model forecasts (v1 notes only, never faked).
