    Cosine = similarity in 64-d space (1.00 = identical direction). The start player's own other seasons are excluded — by person_id, so a twin can never be the same person in a different season. The badge on each twin is the steered trait: a skill grade (0–99) or a raw-stat era-z score.

    ⚠️ Read this before you trust a slide — limits, stated plainly

    • Steering is linear, not a model rerun. We take the saved 64-d embedding, add a fixed direction vector times a slider value, re-normalize, and re-rank. The model itself never runs and never sees the steered point.
    • Directions are correlations, not model internals. A skill direction is just “average embedding of high-skill players minus average of low-skill players.” It shows where high-skill players sit in embedding space; it does not prove the model uses that skill, and sliding can drag along correlated traits (e.g. more shooting also pulls in more scoring).
    • Tower-level steering is NOT available in v0. Tower outputs are not a saved asset, and the saved mtnn.onnx is a stale 119→48 export, not the served v5 — it is not used here. No tower claim is made anywhere on this page.
    • Some sliders saturate — honestly. A player already near the top of a trait (Curry on scoring, 97/99) barely moves when you push that trait further up; the interesting move is downward. The “What moved” box shows the number either way, including when it barely changes.
    • Watch out for the two spaces. The famous Curry → Ginobili pair is a 14-d stat-space Twin Reveal pair. In this page's 64-d embedding space that pair scores only 0.4003 and ranks 390th (person-excluded) — it is not a 64-d top twin. This page's top twin for Curry 2016-17 is James Harden 2017-18 (0.8600). Never mix the two spaces up.

    Data provenance

    Champion model: mtnn_v5_concat_b2_h160_t32_d64_mlp128_fus256 (incumbent 2026-07-25). Embeddings: mtnn_embeddings.f32, 12,966 player-seasons × 64 dimensions, L2-normalized. Skills: skills.json grades (12 skill columns; the meta file lists 18 skill keys but only these 12 grade columns exist, so only these 12 are used). Stats: vectors.json, 14 per-100 stats, z-scored within season. Archetype centers: mtnn_meta.json, 8 centroids in 64-d. Twin search covers the full 12,966-row space on every slider step; every twin shown is a real computed row (name, season, cosine). Baked data: data.js / data.json, produced by precompute.py — re-run it to reproduce every number on this page. This demo runs by opening index.html directly: relative paths only, no server, no external fetches.

    Prototype only. No training, no GPU, no production writes. SAE-based steering is a v1 design note in NOTES.md — it is not implemented here and nothing on this page pretends otherwise.
