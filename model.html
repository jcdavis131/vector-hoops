v4 is shallow: 4 linear layers to embedding, 57% of params in one fusion layer, concat with no cross-family attention, 48-d shared for 8+5+14+18 heads. Capacity caps around 86.0–86.5.

v6 upgrade path: 120 feats → robust scaling median/IQR clip[-3,3] per-season → 17 families cat([x·m,m]) → towers d 40 h 192 ×3 blocks → 17×40 tokens project to 128 → CLS + season 12→128 + 17 tokens =19 tokens → Transformer encoder 128 d_model 4 layers 4 heads FF 512 dropout 0.15 → CLS 128→512→64 L2 unit sphere. Heads MLP 128 hidden, skills 64→24→1. ~1.2M params, still fits 12GB. Target CQS 87.5–88.0, purity 0.89–0.91.

Exact v6 training command — run from vector-hoops/

python pipeline/train_mtnn.py --epochs 150 --dim 64 --tower-width 40 --tower-hidden 192 --tower-blocks 3 --mlp-heads --d-head-hidden 128 --fusion transformer --d-model 128 --n-fusion-layers 4 --n-attn-heads 4 --fusion-hidden 512 --lr 0.001 --lr-schedule onecycle --warmup-pct 0.1 --anneal-strategy linear --weight-decay 0.0002 --nce-loss hybrid --nce-player-weight 0.65 --nce-arch-weight 0.35 --hard-neg-boost 0.4 --drop-p 0.15 --checkpoint-metric cqs --val-every 5 --era-align procrustes --robust-scaling --phase auto

Preprocessing: --era-align procrustes chains drift.json back to 1996-97 root RᵀR=I, --robust-scaling median/IQR per-season clip[-3,3]. Loss: NCE hybrid player 0.65 arch 0.35 + archetype/position/profile/next/skills/salary/team_fit/roster_lift/form_recon/career_slope/competition/pedigree/playoff/honors. Split: player leakfree. Optim: AdamW no decay bias/LN. Scheduler: OneCycle warmup 10% linear.

ChimeraEquation — how Chimera scores
Donor A + Donor B → fuse in 48-d → nearest real player-season among 12,966 by cosine. The argmin that powers the daily puzzle: closest to the sum of two fingerprints.
