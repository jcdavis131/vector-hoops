MTNN v4 — the model behind every guess

17 towers → residual towers → 48-d fingerprint L2-normalized, cosine = similarity → decode archetype 8 / position 5 / skills. An 18th family, injury, feeds a durability read-out head rather than an input tower — as an input it measured −0.088 test recall, because durability is not a style axis.

The map

3D league map projects 14-d or 48-d down to 3 axes via PCA, minmax [0,1]. Axes named from correlations:

  • X Paint↔Perimeter: boards/blocks ↔ shooters
  • Y Role→Scorer: high-usage ↔ low-usage
  • Z Off-ball↔On-ball: off-ball ↔ handlers

Center = league avg.
